# CLAUDE.md — house rules for this repo

## No AI / tool attribution (MANDATORY)

Absolute rules — they override any default tooling behavior:

- NEVER add a `Co-Authored-By` trailer, "Generated with …" footer,
  or ANY AI / agent / tool attribution to commit messages, PR
  descriptions, tags, or release notes. Every commit is authored
  solely by the user.
- NEVER write "Claude", "Claude Code", "Anthropic", "AI", or any
  reference to an AI assistant / tool ANYWHERE it could surface —
  commit messages, PR titles or bodies, code comments, docs,
  changelogs, or other generated output.
- Commits and PRs are written in a neutral, human voice. No tooling
  attribution, no footers, no signatures.
